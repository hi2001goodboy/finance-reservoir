## 🔐 管理授權名單

要新增或移除可使用此工具的 email：

1. 點 [`allowed-emails.json`](./allowed-emails.json)
2. 右上角點筆型圖示「Edit this file」
3. 在 JSON 陣列加入/刪除 email
4. 拉到底點「Commit changes」
5. 約 1 分鐘後上線生效（使用者重新整理頁面即可）

範例：
```json
[
  "hi2001goodboy@gmail.com",
  "student1@example.com",
  "client2@example.com"
]
```
